This is an MSIT Training exercise to create a Blog.

**It contains the following topics:** 
- The use of Union
- Using self-defined Classes for Exceptions
- Use of Flask with render_template with template inheritance and 
Jinja2 variable handling in template htmls (index.html/layout.html)
- The best AJAX html page ever
- A great way of testing Flask with unit test cases
- Mix of Classes with Flask
- using magic method __contains__()
- Image handling in adding a new post
- Use of JSON file storage
- use of decorators
